# Anubhav Rawat | Portfolio

> A dark, terminal-inspired portfolio for Anubhav Rawat, a full-stack developer and final-year Computer Science student.

The site brings together selected projects, technical skills, a downloadable resume, and direct contact links in a lightweight single-page experience.

## Built with

- React 18
- Vite
- Tailwind CSS
- Framer Motion
- JavaScript

## Featured work

- **[BEAM](https://github.com/Anubhavrawat18/BEAM)** - Real-time chat with React, Node.js, MongoDB, and Socket.io.
- **[HireOn](https://github.com/Anubhavrawat18/mock-interview)** - AI-powered mock interview platform.
- **[Fractal Chaotic Auth](https://github.com/Anubhavrawat18/Fractal-Chaotic-Auth)** - Behavioral authentication using chaos-based, time-bound OTPs.
- **[Subscription Tracking API](https://github.com/Anubhavrawat18/Subscription-Tracker-API)** - REST API for subscription management with Node.js, Express, and MongoDB.

## Run locally

```bash
npm install
npm run dev
```

The development server will print the local URL in the terminal. To create a production build:

```bash
npm run build
```
